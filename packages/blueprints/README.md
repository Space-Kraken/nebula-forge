# @space-kraken/nebula-forge-blueprints

Reference architectures for [Nebula Forge]: `serverless-api`,
`queue-processing`, `scheduled-tasks`, `web-app` and `event-driven` —
complete, opinionated starting points consumed by `forge new --blueprint`.

You normally don't install this directly: it comes with
[`@space-kraken/nebula-forge`](https://www.npmjs.com/package/@space-kraken/nebula-forge)
(the CLI).

[Nebula Forge]: https://github.com/Space-Kraken/nebula-forge#readme
